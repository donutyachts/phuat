# Runs

One folder per test pass, named by date (`YYYY-MM-DD/`), each containing:

- `index.html` — cloned from `../../template/report-template.html`, one evidence card per executed test case.
- `evidence/` — GIF (required) and optional screenshot per test case, named by test case ID (e.g. `SUBU-01.gif`).

After publishing a run, add a link to it in the "Run history" section of the top-level `index.html`.
